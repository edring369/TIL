## 0. 객체지향 개요
객체지향은 코드 내의 모든 것을 객체로 표현하려는 프로그래밍 패러다임이다. 기계 관점(절차지향)에서 사람관점(객체지향)으로 변화한 것으로 `class`라는 문법을 통해 표현한다.

- 객체지향 언어의 3가지 특성
  - 캡슐화: 코드와 코드의 데이터 결합하여, 정보를 은닉한다.
  - 상속성: 한 객체가 다른 객체의 특성을 획득한다.
  - 다형성: 하나의 인터페이스(interface)를 통해 일반적인 클래스의 행위들을 접근할 수 있도록 한다.
## 1. 클래스
### 1.1 클래스란?
클래스(class)는 객체를 만들기 위한 청사진, 틀을 제공하는 **자료형**이다. 
`new`로 인스턴스 객체를 생성하여 사용한다. 인스턴트 객체란 클래스에 의해 생성된 실체로 메모리에 생성된 **값**이다.

접근 제한자로 캡슐화(은닉성)를 구현한다.
- `private`: 클래스의 내부에서만 접근 가능, 파생 클래스도 접근 불가
- `public`: 클래스의 내/외부 모두 접근 가능
- `protected`: 파생 클래스에서만 접근 가능

예제) 클래스 객체 생성
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        Cat cat = new Cat(); //인스턴스: cat, C#에서는 new로 인스턴스 객체 생성
        cat.name = "Kitty"; 
        cat.color = "White";
        cat.Meow();
    }
}

class Cat
{
    public string name;  //멤버 변수(필드)
    public string color; //멤버 함수(메서드)
    public void Meow() { Console.WriteLine("야옹"); }
}
```

### 1.2 생성자
생성자는 객체 멤버의 값을 초기화 한다. 생성자의 특징은 아래와 같다.
- 클래스 이름과 같다.
- 반환 형식이 없다.
- 기본생성자는 정의하지 않아도 자동 생성된다.
- 사용자가 생성자를 정의하면 기본생성자는 자동으로 생성되지 않는다.

예제) 생성자 예제 
```cs
using System;

class Program
{

    static void Main(string[] args)
    {
        Cat cat = new Cat() { name = "Yaong" };
        Console.WriteLine(cat.name); // Yaong 출력
    }
}
internal class Cat
{
    public string name;  //멤버 변수(필드)
    public string color; //멤버 함수(메서드

    public Cat() // 생성자는 외부에서 생성하려고 만드는 것이니 public으로 선언
    {
        name = "Kitty";
        color = "White";
    }
    public void Meow() { Console.WriteLine("야옹"); }
}
```
### 1.3 this
`this`는 객체의 멤버 함수 내부에서 사용 가능한 특별한 포인터이다. 객체 내부에서 자신의 필드나 메소드에 접근할 때 사용한다.
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        Employee e1 = new Employee(); e1.SetName("직원 1"); //this.Name은 e1의 Name을 의미
        Employee e2 = new Employee(); e2.SetName("직원 2"); //이 this.Name은 e2의 Name을 의미
    }
}
class Employee
{
    private string Name;    //이름
    private int Price;      //급여
    public void SetName(string Name) 
    {
        //Name = Name; //이름이 멤버변수와 똑같다. 왼쪽 Name이 매개 변수로 인식하고 있다.
        this.Name = Name;
    }
}
```
### 1.4 Property
프로퍼티는 함수인데 변수처럼 사용하게 만든다. 객체를 안전하게 주고받고 관리하기 위해 은닉성과 편의성을 위해 프로퍼티를 사용한다. 사용은 변수처럼 사용하고 정의는 함수처럼 구현되어 은닉이 가능하다.

```cs
using System;
class Program
{
    static void Main(string[] args)
    {
        MyClass obj = new MyClass();
        obj.MyField = 1000;             //write
        Console.WriteLine(obj.MyField); //read

        //obj.Set(1000);
        //Console.WriteLine(obj.Get());
    }
}

class MyClass 
{
    private int myField;
    
    //public int MyField { get; set; } //내부 구현이 필요 없을 때 프로퍼티 선언
    public int MyField 
    {
        get { return this.myField; }                            //read
        set { if (value > 100) return;  this.myField = value; } //write
    }

    //public int Get() {  return myField; }
    //public void Set(int a) { myField = a; }
}
```
### 1.5 static
static은 클래스 자체에 속하는 멤버를 만들 때 사용한다. 클래스 이름으로 접근하여 사용한다.
```cs
using System;
class Program
{ 
    static void Main(string[] args)
    {
        MyClass myClass = new MyClass();
        myClass.a = 1;      //인스턴스 필드 접근 -> 객체 생성 필요

        MyClass.b = 2;      //정적 필드 접근 -> 객체 생성 필요X  
        MyClass.Func2();    
    }
    class MyClass //static class MyClass // 정적 클래스: 모든 멤버가 static인 경우, 인스턴스가 하나도 없는 경우
    {
        public int a;        //인스턴스 멤버
        public static int b; //클래스 멤버  //정적 필드
		
        public void Func1() { }       //인스턴스 멤버
        public static void Func2() { } //클래스 멤버  //정적 메서드
        static MyClass() //정적 생성자: 정적 멤버의 초기화 할 때 사용
		{
		    b = 0;
		}
    }
}
```
## 2. 상속과 다형성
객체지향 언어의 특성 중 하나이다. 다형성은 하나의 인터페이스를 통해 일반적인 클래스의 행위들을 접근할 수 있는 성질이다.
> 하나의 인터페이스로, 여러 메소드를!
### 2.1 상속
상속의 목적은 코드를 재활용하고 객체들 간의 관계를 구축하는 것이다.
추상화 범위는 부모클래스(기반 클래스)가 더 크나, 자식클래스(파생클래스)가 메모리가 더 크다.

C#에서는 C++과 달리 다중 상속이 안 된다. -> 인터페이스(interface)로 바꿔서 상속
```cs
class Fly { }
class Run { }
class FlyCar: Fly, Run { } //다중 상속X

interface IFly { }
interface IRun { }
class FlygCar : IFly, IRun { } //다중 상속O
```

자기 자신은 `this`, 부모는 `base`
`protected`: 자식클래스에서만 부모 멤버에 접근할 수 있다.

```cs
using System;

class Program
{ 
    static void Main(string[] args)
    {   
        Gun gun = new Gun();
        gun.Reload();           //재장전하기
        gun.Attack();           //공격하기(부모 활용)

        Weapon[] weapons = new Weapon[] {
            new Gun(),
            new Knife(),
            new Bow(),
        };

        Weapon weapon = new Gun();  weapon.Attack();
        weapon = new Knife();       weapon.Attack();  //무기 교체
    }
}

//칼, 활, 총                     ->무기라는 개념으로 추상화 (is a 관계)
class Weapon
{
    protected int power;        //공격력
    public void Attack() { }    //공격하기
}

class Knife : Weapon { }

class Bow : Weapon { }

class Gun : Weapon
{
    private int magazine;       //탄창
    public void Attack() { magazine--; }
    public void Reload() { magazine = 10; } //재장전 하기
}
```

### 2.2 object
`object`는 모든 타입(값, 참조 타입)의 최상위 부모 클래스이다. 따라서 어떤 타입이든 담을 수 있다.
그러나 값 형식을 담으면 박싱, 언박싱이 필요하다는 단점이 있다.

- `object`가 기본으로 가지고 있는 메서드
	- `ToString()`: 객체를 문자열로 표현
	- `Equals(object)`: 두 객체가 같은지 비교
	- `GetHashCode()`: 해시코드 반환
	- `GetType()`: 런타임 타입 정보 반환

```cs
object[] mixed = { 1, "two", 3.0, true };  // 타입 제각각 저장 가능
```
### 2.3 다형성
상속을 하다보면 다양한 클래스가 생긴다. 하지만 형변환으로 부모 자식을 찾는 게 불편하다. 이를 개선하기 위해 부모로 사용하여 여러 자식들을 알아서 사용하도록 한다. 즉 다형성은 쓰는 것은 한 가지인데 여러가지 의미를 가지는 것이라고 할 수 있다. 
- 다형성을 구현하는 방법
	- 오버라이딩
 	- 인터페이스
    - 제네릭 등
 
### 2.4 virtual
`virtual`: 자식 클래스가 재정의할 수 있도록 허용(가상 메서드 선언)한다.
### 2.5 override
오버라이딩이란 부모 클래스에 있는 메서드를 자식 클래스에서 같은 이름으로 재정의 하는 것이다.
- `overried`: 자식 클래스가 재정의할 수 있도록 허용(메서드 재정의)한다.
- 업캐스팅: 부모 형식으로 형변환
- 다운캐스팅: 자식 형식으로 형변환(주의!)

예제) 인벤토리 만들기
```cs
//무기 - name, level, Attack(Attack power), Use()
//방어구 - name, level, Defence(defence power), Use()

using System;

class Program
{ 
    static void Main(string[] args)
    {
        //아이템 목록 { 단검, 장검, 갑옷 }
        Item[] items = new Item[]
        {
            new Weapon("단검", 2, 100),
            new Weapon("장검", 2, 200),
            new Armor("갑옷", 1, 50),
        };

        foreach (Item item in items)
        {
            Console.WriteLine(item);
        }
        //아이템을 사용하는 코드
        ItemUse(items[0]); //보통 아이템의 ID로 사용한다.
    }

    //아이템을 사용하는 코드 Use()
    static void ItemUse(Item item)
    {
        item.Use();
    }
}

class Item
{
    public string Name;
    public int Level; //프로퍼티로 많이 쓰기 때문에 대문자로(?) #보완
    public Item(string Name, int Level) { this.Name = Name; this.Level = Level;}
    public virtual void Use() { Console.WriteLine("Use Item"); }
}

class Weapon : Item
{
    public int Attack;
    public Weapon(string Name, int Level, int Attack) : base(Name, Level) { this.Attack = Attack; }
    public override void Use() { Console.WriteLine("Use Weapon"); }
}

class Armor : Item
{
    public int Defence;
    public Armor(string name, int level, int Defence) : base(name, level) { this.Defence = Defence; }
    public override void Use() { Console.WriteLine("Use Armor"); }
}
```
