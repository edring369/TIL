## 0. C# 프로그래밍 개요

C#은 Microsoft에서 개발한 **객체 지향 언어(Object-Oriented Programming)** 이다.
- .NET 플랫폼에서 실행된다.(다양한 라이브러리 제공)
- 문법이 간결하다.
- Unity 엔진 등에서 사용된다.
  
### 기본 입출력
C# 프로그램이 정상적으로 실행되는지 확인하기 위한 가장 기본적인 예제이다.
- `Console.WriteLine()` 메서드를 사용한다.

```csharp
using System;

public class Program 
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello World");
    }
}
```
이외에 포맷 지정자, 문자열 보간법 출력 등이 있다.

## 1. 자료형
- 정수형: `byte`, `short`, `int`, `long`
- 실수형: `float`, `double`, `decimal`
- 문자형: `char`
- 논리형: `bool`

  
<details>
  <summary>예제) 자료형의 범위와 크기 확인하기</summary>
  
  ```
using System;

class Program
{
    static void Main(string[] args)
    {
        int n = 0;
        Console.WriteLine(int.MinValue);
        Console.WriteLine(int.MaxValue);
        Console.WriteLine(byte.MinValue);
        Console.WriteLine(byte.MaxValue);   

        Console.WriteLine(sizeof(int));     //4
        Console.WriteLine(sizeof(char));    //2
        Console.WriteLine(sizeof(float));   //4
        Console.WriteLine(sizeof(double));  //8
        Console.WriteLine(sizeof(decimal)); //16

        char ch = 'A';
        System.Console.WriteLine((int)ch);  //65
    }
}
```
</details>

## 2. 배열
자료형이 같은 데이터를 한 번에 다뤄야 하는 경우 사용한다.

```cs
//배열 선언과 초기화

{
    static void Main(string[] args)
    {

        int[] array4 = new int[3];            

        for (int i = 0; i < array1.Length; i++)
        {
            Console.WriteLine(array1[i]);
        }
    }
}
```
## 3. 연산자
- 산술 연산자
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        int result1 = 123 + 456;        //산술 연산자
        Console.WriteLine(result1);

        string result2 = "123" + "456"; //문자열 결합 연산자
        Console.WriteLine("123" + 456); //123456

        Console.WriteLine('0' + '1');   //문자 덧셈은 정수취급 //97
    }
}
```
- 논리 연산자
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
       Console.WriteLine(1 > 0 && 2 < 3);
       string result = (10 % 2) == 0 ? "짝수" : "홀수"; //삼항연산자 //조건이 참이면 좌, 거짓이면 우
       Console.WriteLine(result);

       string str = null;
       Console.WriteLine($"{str ?? "0"}"); //Null 병합 연산자 str이 null이면 0 출력

       int? h = null;  //Nullable
       Console.WriteLine($"b ?? 10 : {h ?? 10}"); //값이 있으면 출력, null이면 10 출력
    }
}
```

## 4. 제어문
### 4.1 조건문
- if문
```cs
using System;

class Program
{      
    static void Main(string[] args)
    {
        int number = 0;
        if(number % 2 == 0 && number > 0)
        {
            System.Console.WriteLine("0보다 큰 짝수");
        }
        else if(number % 2 == 1 && number > 0)
        {
            System.Console.WriteLine("0보다 큰 홀수");
        }
        else System.Console.WriteLine("0보다 작거나 같은 수");
    }
}
```

- switch문
```cs
using System;

enum Season
{
    Spring,
    Summer,
    Fall,
    Winter
}      

class Program
{
    static void Main(string[] args)
    {
        Season ss = Season.Spring;
        switch (ss)
        {
            case Season.Spring:
                break;
            case Season.Summer:
                break;
            case Season.Fall:
                break;
            case Season.Winter:
                break;
        }
    }
}
```
### 4.2 반복문
- while문
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        int i = 0;
        while (i < 3)
        {
            System.Console.WriteLine("Hi");
            i++;
        } 
    }
}
```

- for문
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        for (int j = 0; j < 3; j++) // 
        {
            System.Console.WriteLine("Hi");
        }
    }
}
```

## 5. 함수
함수(메서드)는 특정 기능을 하나의 이름 아래 묶은 것이다. 
```cs
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine(Plus1(3,2)); 
        Console.WriteLine(Calc.Plus2(3, 2)); //정적 함수는 클래스의 이름 //static X -> 객체 생성 후 사용한더다.
    }   

    public static int Plus1(int n1, int n2)
    {
        return n1 + n2;
    }
}

class Calc
{
    public static int Plus2(int n1, int n2)
    {
        return n1 + n2;
    }
}

```
