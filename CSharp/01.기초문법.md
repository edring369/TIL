## 0. C# 프로그래밍 개요

C#은 Microsoft에서 개발한 **객체 지향 언어(Object-Oriented Programming)** 이다.
- .NET 플랫폼에서 실행된다.(다양한 라이브러리 제공)
- 문법이 간결하다.
- Unity 엔진 등에서 사용된다.
  
### 기본 입출력
C# 프로그램이 정상적으로 실행되는지 확인하기 위한 가장 기본적인 예제이다.
- `Console.WriteLine()` 메서드를 사용한다.

```csharp
using System;

public class Program 
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello World");
    }
}
```
이외에 포맷 지정자, 문자열 보간법 출력 등이 있다.
